# View earlier versions of a questionnaire

## Overview

  <track kind="captions" src="/media/definitions/questionnaire/view-questionnaire-versions.vtt" srcLang="en" label="English" default />
</video>

This flow describes how to see the earlier versions of a [questionnaire](../../../concepts/definitions/questionnaire.mdx). Each time someone saves changed questions, Care raises the version number and keeps the earlier questions as a past version.

## Pre-requisites

- The questionnaire is in your facility, and you can open it.
- You are a member of a department of the facility, so the facility sidebar shows **Settings**.
- If you want to see a past version, the questions changed at least once. Until then, Care shows "No previous versions yet".
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can Read Questionnaires | Lets you open the questionnaire, its **Versions** tab and its past versions. You must hold it in the facility's root organization (**Administration**), in a department that the questionnaire is shared with, or in a department above one. A past version keeps the departments that the questionnaire was shared with when that version was replaced. If a department was shared later, its members do not see that past version in the list and cannot open it. By default, the Facility Admin, Administrator, Doctor, Nurse, Staff, Pharmacist and Volunteer roles hold it. |

## Steps

### 1. Open the questionnaire

In the facility sidebar, select **Settings**. In the settings sidebar, under **Forms**, select **Questionnaires**.

The list shows **Active** questionnaires. If the questionnaire has another status, select the **Draft** or **Retired** tab. Select the questionnaire in the list.

![Step 1, Open the questionnaire: the screen at this step, with the control for the step outlined](/media/definitions/questionnaire/view-questionnaire-versions-1.png)

### 2. Open the version history

Select the **Versions** tab. Care shows the **Version history**.

The current version comes first, with its version number and status. The past versions follow, newest first. Each past version has the **Retired** badge.

Each version shows who created it, under **Created By**, and who changed it last, under **Last Modified By**.

![Step 2, Open the version history: the screen at this step, with the control for the step outlined](/media/definitions/questionnaire/view-questionnaire-versions-2.png)

### 3. Open a past version

On the past version, select **Open**.

Care shows the questions of that version in read-only form. The page shows the **Past revision** badge and the current version number, for example "Current version: v3".

Note: You cannot change a past version, and people cannot fill it in.

![Step 3, Open a past version: the screen at this step, with the control for the step outlined](/media/definitions/questionnaire/view-questionnaire-versions-3.png)

### 4. Go back

To return to the **Versions** tab, select **Back**.

To work on the current version, select **Continue Editing** on it. Care opens the question editor. If you cannot edit the questionnaire, the button is **Open**, and the editor opens in preview only.

![Step 4, Go back: the screen at this step, with the control for the step outlined](/media/definitions/questionnaire/view-questionnaire-versions-4.png)

## Expected Outcome

- You see the questions of each earlier version as they were before they changed.
- Each response records the version of the questionnaire that was filled in.
