# Create a questionnaire

## Overview

<video src="/media/definitions/questionnaire/create-questionnaire.mp4" poster="/media/definitions/questionnaire/create-questionnaire.poster.png" controls width="720">
  <track kind="captions" src="/media/definitions/questionnaire/create-questionnaire.vtt" srcLang="en" label="English" default />
</video>

This flow describes how to create a new [questionnaire](../../../concepts/definitions/questionnaire.mdx) in your facility. You give the questionnaire a title, a slug, a status, and a subject type, and you save it. You add the questions after you save it.

## Pre-requisites

- You are a member of a department of the facility, so the facility sidebar shows **Settings**.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can Create/Update Questionnaires | Shows **Create Questionnaire** and lets you save the new questionnaire. You must hold it in the facility's root organization (**Administration**). By default, the Facility Admin role holds it. |
| Can Read Questionnaires | Lets you see the questionnaire list, and open the new questionnaire after you save it. You must hold it in the root organization, because the new questionnaire is not shared with any department yet. By default, the Facility Admin, Administrator, Doctor, Nurse, Staff, Pharmacist and Volunteer roles hold it. |

## Steps

### 1. Open the questionnaire list

In the facility sidebar, select **Settings**. In the settings sidebar, under **Forms**, select **Questionnaires**.

Care shows the questionnaires of your facility.

![Step 1, Open the questionnaire list: the screen at this step, with the control for the step outlined](/media/definitions/questionnaire/create-questionnaire-1.png)

### 2. Start a new questionnaire

Select **Create Questionnaire**. Care opens the **Create Questionnaire** page, with a **Facility** badge next to the heading.

Note: If you do not see **Create Questionnaire**, you do not hold "Can Create/Update Questionnaires" in the root organization.

![Step 2, Start a new questionnaire: the screen at this step, with the control for the step outlined](/media/definitions/questionnaire/create-questionnaire-2.png)

### 3. Fill in the basic information

Complete the fields under **Basic Information**.

| Components | What it captures |
| --- | --- |
| Title | The name of the questionnaire. This field is required. |
| Slug | A short name that identifies the questionnaire in your facility. This field is required. Care fills it in from the title as you type. |
| Description | More information about the questionnaire. This field is optional. |

The slug must have 5 to 50 characters. Use only letters, numbers, hyphens and underscores, and start and end with a letter or a number.

The slug must not match the slug of another questionnaire in your facility. Care ignores capital letters in this check.

![Step 3, Fill in the basic information: the screen at this step, with the control for the step outlined](/media/definitions/questionnaire/create-questionnaire-3.png)

### 4. Set the questionnaire properties

In the **Questionnaire Properties** panel, set the fields below.

| Components | What it captures |
| --- | --- |
| Status | Select Active, Draft or Retired. The default is Draft. Staff can fill in the questionnaire only when it is Active. |
| Subject Type | What the questionnaire is about. Select Encounter, Referral, Location, Device or Facility. The default is Encounter. |

Note: You cannot change the subject type after you save the questionnaire.

Note: The **Version** shows v1. Care sets the version, and you cannot change it.

![Step 4, Set the questionnaire properties: the screen at this step, with the control for the step outlined](/media/definitions/questionnaire/create-questionnaire-4.png)

### 5. Save the questionnaire

Select **Save Questionnaire**.

Note: You do not add questions on this page. The **Questions** box shows "Save the questionnaire, then use Edit Questions to add questions."

Note: To leave without saving, select **Cancel**. If you entered data, Care asks you to confirm.

![Step 5, Save the questionnaire: the screen at this step, with the control for the step outlined](/media/definitions/questionnaire/create-questionnaire-5.png)

## Expected Outcome

- Care shows the message "Questionnaire created successfully!".
- Care opens the page of the new questionnaire. The questionnaire has no questions yet.
- The questionnaire shows in the **Questionnaires** list, under the tab of its status.
- The questionnaire is not shared with any department. Until you share it, only people who hold Can Read Questionnaires in the root organization can see it.
