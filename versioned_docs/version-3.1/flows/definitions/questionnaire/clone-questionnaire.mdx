# Clone a questionnaire

## Overview

<video src="/media/definitions/questionnaire/clone-questionnaire.mp4" poster="/media/definitions/questionnaire/clone-questionnaire.poster.png" controls width="720">
  <track kind="captions" src="/media/definitions/questionnaire/clone-questionnaire.vtt" srcLang="en" label="English" default />
</video>

This flow describes how to copy a [questionnaire](../../../concepts/definitions/questionnaire.mdx) in your facility. Care creates a new draft questionnaire with the same questions.

## Pre-requisites

- The questionnaire is saved in your facility, and you can open it.
- You are a member of a department of the facility, so the facility sidebar shows **Settings**.
- If the questionnaire has actions, you are allowed to use each of its actions. The copy keeps them.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can Create/Update Questionnaires | Shows **Clone Questionnaire** and lets you create the copy. You must hold it in the facility's root organization (**Administration**). By default, the Facility Admin role holds it. |
| Can Read Questionnaires | Lets you open the questionnaire, and the copy after Care creates it. For the original, you must hold it in the root organization, in a department that the questionnaire is shared with, or in a department above one. For the copy, you must hold it in the root organization, because the copy is not shared with any department yet. By default, the Facility Admin, Administrator, Doctor, Nurse, Staff, Pharmacist and Volunteer roles hold it. |

## Steps

### 1. Open the questionnaire

In the facility sidebar, select **Settings**. In the settings sidebar, under **Forms**, select **Questionnaires**.

The list shows **Active** questionnaires. If the questionnaire has another status, select the **Draft** or **Retired** tab. Select the questionnaire in the list.

![Step 1, Open the questionnaire: the screen at this step, with the control for the step outlined](/media/definitions/questionnaire/clone-questionnaire-1.png)

### 2. Start the clone

On the questionnaire page, select **Clone Questionnaire**. Care opens the **Clone Questionnaire** dialog.

Note: You can also select **Clone Questionnaire** in **Form Settings** in the question editor.

![Step 2, Start the clone: the screen at this step, with the control for the step outlined](/media/definitions/questionnaire/clone-questionnaire-2.png)

### 3. Check the title and the slug

Care fills in both fields from the original questionnaire. Keep the values, or change them.

| Components | What it captures |
| --- | --- |
| **Title** | The name of the copy. Care fills in the original title, followed by "(Copy)". |
| **Slug** | A short name that identifies the copy in your facility. Care fills in the original slug, followed by "-copy". |

The slug must have 5 to 50 characters. Use only letters, numbers, hyphens and underscores. Start and end with a letter or a number.

The slug must not match the slug of another questionnaire in your facility. Care ignores capital letters in this check.

![Step 3, Check the title and the slug: the screen at this step, with the control for the step outlined](/media/definitions/questionnaire/clone-questionnaire-3.png)

### 4. Create the copy

Select **Clone Questionnaire**.

Note: To close the dialog without a copy, select **Cancel**.

![Step 4, Create the copy: the screen at this step, with the control for the step outlined](/media/definitions/questionnaire/clone-questionnaire-4.png)

## Expected Outcome

- Care shows "Questionnaire cloned successfully" and opens the copy.
- The copy is a **Draft** in your facility. It has the same subject type, description and questions as the original.
- The copy starts at version v1, with no past versions.
- The copy is not shared with any department. Until you share it, only people who hold Can Read Questionnaires in the root organization can see it.
- People can fill in the copy only after you set its status to **Active**.
