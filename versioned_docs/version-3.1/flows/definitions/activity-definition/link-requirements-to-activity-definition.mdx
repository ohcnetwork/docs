# Link requirements to an activity definition

## Overview

<video src="/media/definitions/activity-definition/link-requirements-to-activity-definition.mp4" poster="/media/definitions/activity-definition/link-requirements-to-activity-definition.poster.png" controls width="720">
  <track kind="captions" src="/media/definitions/activity-definition/link-requirements-to-activity-definition.vtt" srcLang="en" label="English" default />
</video>

This flow describes how to link specimen definitions, observation definitions and charge item definitions to an [activity definition](../../../concepts/definitions/activity-definition.mdx). It also describes how to choose the healthcare service and the locations. All of these are in the **Requirements** section of the activity definition form.

## Pre-requisites

- You are creating an activity definition, or you are editing one. See [Create an activity definition](./create-activity-definition.mdx) or [Update or retire an activity definition](./update-or-retire-activity-definition.mdx).
- The specimen definitions, observation definitions and charge item definitions that you want to link are Active and belong to your facility.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can Create Activity Definition on Facility | Lets you save the activity definition with its requirements. You must hold it in the facility's root organization (**Administration**). By default, the Facility Admin role holds this permission. |
| Can Read Activity Definition | Lets you open an activity definition to edit it. You can hold it in any department of the facility. By default, the Facility Admin, Administrator, Staff, Doctor, Nurse and Volunteer roles hold this permission. |
| Can Read Specimen Definition | Lets you see the specimen definitions in **Select Specimen Requirements**. You can hold it in any department of the facility. By default, the Facility Admin, Administrator, Staff, Doctor, Nurse, Volunteer and Pharmacist roles hold this permission. |
| Can Read Observation Definition | Lets you see the observation definitions in **Select Observation Requirements**. You can hold it in any department of the facility. By default, the Facility Admin, Administrator, Staff, Doctor, Nurse, Volunteer and Pharmacist roles hold this permission. |
| Can Read Charge Item Definition | Lets you see the charge item definitions in **Select Charge Item Definitions**. You can hold it in any department of the facility. By default, the Facility Admin, Administrator, Staff, Doctor, Nurse, Volunteer and Pharmacist roles hold this permission. |
| Can Read Resource Category | Lets you browse the charge item definition categories in **Select Charge Item Definitions**. You can hold it in any department of the facility. By default, the Facility Admin, Administrator, Staff, Doctor, Nurse, Volunteer and Pharmacist roles hold this permission. |
| Can Read Healthcare Service | Lets you choose the **Healthcare Service**. You can hold it in any department of the facility. By default, the Facility Admin, Administrator, Staff, Doctor, Nurse, Volunteer and Pharmacist roles hold this permission. |
| Can List Facility Locations | Lets you choose the **Locations**. Care lists only the locations of the departments where you hold it. If you hold it in the root organization, Care lists every location of the facility. By default, the Facility Admin, Administrator, Staff, Doctor, Nurse and Pharmacist roles hold this permission. |
| Can Create Specimen Definition on Facility | Needed only to make a new specimen definition with **Create New**. You must hold it in the root organization. By default, the Facility Admin role holds this permission. |
| Can Create Observation Definition on Facility | Needed only to make a new observation definition with **Create New**. You must hold it in the root organization. By default, the Facility Admin role holds this permission. |

By default, the Facility Admin role in the root organization holds every permission in this table.

## Steps

### 1. Open the Requirements section

In the activity definition form, go to the **Requirements** section.

![Step 1, Open the Requirements section: the screen at this step, with the control for the step outlined](/media/definitions/activity-definition/link-requirements-to-activity-definition-1.png)

### 2. Link specimen requirements

1. Select **Select Specimen Requirements**.
2. Search for a [specimen definition](../../../concepts/definitions/specimen-definition.mdx).
3. Select the specimen definition.
4. Repeat for each sample that the service needs.

Care lists only the active specimen definitions of the facility. You can add the same specimen definition more than once.

To make a new specimen definition, select **Create New**. Care opens the specimen definition form in a panel. When you save it, Care closes the panel and adds the new definition to the list. Care does not select it for you, so select it in the list.

![Step 2, Link specimen requirements (1 of 2): the screen at this step, with the control for the step outlined](/media/definitions/activity-definition/link-requirements-to-activity-definition-2.png)

![Step 2, Link specimen requirements (2 of 2): the screen at this step, with the control for the step outlined](/media/definitions/activity-definition/link-requirements-to-activity-definition-3.png)

### 3. Link observation requirements

1. Select **Select Observation Requirements**.
2. Search for an [observation definition](../../../concepts/definitions/observation-definition.mdx).
3. Select the observation definition.
4. Repeat for each result that the service records.

Care lists only the active observation definitions of the facility. You can add each observation definition only once.

To make a new observation definition, select **Create New**. It works the same way as for a specimen definition: select the new definition in the list after you save it.

![Step 3, Link observation requirements (1 of 2): the screen at this step, with the control for the step outlined](/media/definitions/activity-definition/link-requirements-to-activity-definition-4.png)

![Step 3, Link observation requirements (2 of 2): the screen at this step, with the control for the step outlined](/media/definitions/activity-definition/link-requirements-to-activity-definition-5.png)

### 4. Link charge item definitions

1. Select **Select Charge Item Definitions**.
2. Open the category that holds the [charge item definition](../../../concepts/definitions/charge-item-definition.mdx), or type its title to search.
3. Select each charge item definition that applies to the service. To remove one, select it again.

Care lists only active charge item definitions. Care has no **Create New** option here, so create the charge item definition first. Then link it.

Note: When a clinician orders the service, Care creates a charge for every linked charge item definition. This is also true for a charge item definition that is retired after you link it.

Note: Do not link a charge item definition that has a negative base price. If you do, Care cannot order the service and shows "Total price is less than 0".

![Step 4, Link charge item definitions (1 of 2): the screen at this step, with the control for the step outlined](/media/definitions/activity-definition/link-requirements-to-activity-definition-6.png)

![Step 4, Link charge item definitions (2 of 2): the screen at this step, with the control for the step outlined](/media/definitions/activity-definition/link-requirements-to-activity-definition-7.png)

### 5. Choose the healthcare service and the locations

1. In **Healthcare Service**, select the healthcare service that provides the service. This field is optional.
2. In **Locations**, select the locations where staff do the service.

![Step 5, Choose the healthcare service and the locations (1 of 2): the screen at this step, with the control for the step outlined](/media/definitions/activity-definition/link-requirements-to-activity-definition-8.png)

![Step 5, Choose the healthcare service and the locations (2 of 2): the screen at this step, with the control for the step outlined](/media/definitions/activity-definition/link-requirements-to-activity-definition-9.png)

### 6. Save the activity definition

For a new activity definition, select **Create**. For an activity definition that exists, select **Save**.

![Step 6, Save the activity definition (1 of 3): the screen at this step, with the control for the step outlined](/media/definitions/activity-definition/link-requirements-to-activity-definition-10.png)

![Step 6, Save the activity definition (2 of 3): the screen at this step, with the control for the step outlined](/media/definitions/activity-definition/link-requirements-to-activity-definition-11.png)

![Step 6, Save the activity definition (3 of 3): the screen at this step, with the control for the step outlined](/media/definitions/activity-definition/link-requirements-to-activity-definition-12.png)

## Expected Outcome

- Care saves the requirements with the activity definition.
- The activity definition page shows the requirements in the cards **Specimen Requirements**, **Observation Result Requirements**, **Charge Item Definitions**, **Healthcare Service** and **Locations**.
- The page calls the observation requirements **Observation Result Requirements**. The form calls them **Observation Requirements**.
