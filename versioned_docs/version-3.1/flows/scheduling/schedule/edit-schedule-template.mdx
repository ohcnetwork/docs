# Edit a schedule template

## Overview

<video src="/media/scheduling/schedule/edit-schedule-template.mp4" poster="/media/scheduling/schedule/edit-schedule-template.poster.png" controls width="720">
  <track kind="captions" src="/media/scheduling/schedule/edit-schedule-template.vtt" srcLang="en" label="English" default />
</video>

This flow describes how to change the name, the valid period, the visibility and the encounter defaults of a [schedule template](../../../concepts/scheduling/schedule.mdx). To add or remove a session, see [Add or remove a session in a schedule template](./add-or-remove-schedule-session.mdx); you do this in the same sheet.

## Pre-requisites

- You are a member of the facility.
- The practitioner, location or healthcare service has a schedule template. See [Create a schedule template](./create-schedule-template.mdx).
- You have the permissions listed below, in the place that the list below the table gives for the resource.

## Permissions

| Permission | Access |
| --- | --- |
| Can Create on Schedule | Lets you save the changes. Hold it in the place listed below for the resource. By default, the Admin (facility role), Facility Admin, Doctor, Nurse and Staff roles hold it. |
| Can list schedule on Object | Lets you open the schedule page and load the template into the sheet. Hold it in the place listed below for the resource. For a practitioner, the **Availability** tab shows only if you hold it in a department or team of the facility, or in its Administration organization. By default, the Admin, Facility Admin, Administrator, Doctor, Nurse and Staff roles hold it. |
| Can Read Healthcare Service | Only for a location or a healthcare service. Lets you open **Services** and the healthcare service. Hold it in any organization of the facility. By default, the Admin, Facility Admin, Administrator, Doctor, Nurse, Staff, Volunteer and Pharmacist roles hold it. |
| Can View Facility Organizations | Optional. Lets you choose from all departments of the facility in **Encounter defaults**. Without it, you can choose only the departments that you belong to. By default, the Admin, Facility Admin, Administrator, Doctor, Nurse, Staff and Volunteer roles hold it. |

Care accepts Can Create on Schedule and Can list schedule on Object only in these places:

- For a practitioner: the facility's Administration organization, a department or team that the practitioner belongs to, or a parent of it.
- For a location: a department linked to the location or to its parent location, a parent of that department, or the facility's Administration organization.
- For a healthcare service with a managing organization: that organization or a parent of it. The Administration organization does not count.
- For a healthcare service without a managing organization: only the facility's Administration organization.

Only roles that you hold in the facility's organizations count. A role in a governance organization above the facility does not count.

Care shows the pencil icon on a template card if you hold Can Create on Schedule anywhere in the facility. This includes any department or team of the facility, and its Administration organization. When you save, Care accepts the permission only in the place for the resource.

## Steps

### 1. Open the schedule

Practitioners, locations and healthcare services use the same schedule page. Open it in one of these ways:

- For a practitioner, select **Users** in the facility sidebar. Find the practitioner and select **See Details**. Then select the **Availability** tab.
- For your own schedule, open the account menu and select **Profile**. Then select the **Availability** tab.
- For a location, select **Services** in the facility sidebar. Select a healthcare service. On a location card, select **View appointments**. This link shows for services that are not a store, a pharmacy or a lab. In the location sidebar, under **Scheduling**, select **Schedule**.
- For a healthcare service, select **Services** in the facility sidebar. Select the service. In the service sidebar, under **Scheduling**, select **Schedule**.

![The schedule page of the healthcare service General Medicine OP, with Schedule outlined under Scheduling in the service sidebar](/media/scheduling/schedule/edit-schedule-template-1.png)

Care can show "You do not have permission to update schedule", and the page does not finish loading. Then you do not hold Can list schedule on Object in the place for this resource. Ask your administrator for it.

### 2. Open the template

On the **Schedule** tab, find the template. The tab lists the templates whose valid period overlaps the month on the calendar.

On the template card, select the pencil icon. The **Edit Schedule Template** sheet opens.

![The pencil icon outlined on the Weekday OP template card on the Schedule tab](/media/scheduling/schedule/edit-schedule-template-2.png)

The sheet also lists the sessions of the template under **Availabilities**, and it has a **Delete** button. See [Add or remove a session in a schedule template](./add-or-remove-schedule-session.mdx) and [Delete a schedule template](./delete-schedule-template.mdx).

### 3. Change the details

Change the fields that you need:

| Components | What it captures |
| --- | --- |
| **Template Name** | The name of the template. |
| **Valid Period** | The first and the last day of the template. Here the start date can be in the past. |
| **Make the template public** | Select it to let patients book the slots of the template themselves. Clear it to stop new self-bookings. |
| **Encounter defaults** | The departments, the **Care Team** and the **Type of Encounter** for encounters created from appointments on this template. |

![The Template Name field outlined in the Edit Schedule Template sheet, changed to Weekday General OP](/media/scheduling/schedule/edit-schedule-template-3.png)

![The Valid Period date picker outlined, with Start date 28/11/2026 and the new End date 31/03/2027, above the Apply button](/media/scheduling/schedule/edit-schedule-template-4.png)

The **Encounter defaults** fields become active after Care loads their saved values.

If the end date is before the start date, Care shows "To date must be equal to or after from date".

Care refuses a new valid period that leaves out slots that already have appointments.

If you clear **Make the template public** on a public template, Care shows this warning: "Existing appointments will not be affected. This will only prevent patients from booking new appointments through self-service."

You cannot change the weekdays or the sessions in this form. Each session keeps its own weekdays. To change a session, remove it first, and then add a new session. Care refuses a new session that overlaps a session still in the template. Care also refuses to remove a session while one of its future slots has an appointment. See [Add or remove a session in a schedule template](./add-or-remove-schedule-session.mdx).

### 4. Save the changes

Select **Save**. **Save** is active only after you change a value.

![The message Schedule template updated successfully, with the Valid Period field outlined showing Nov 28, 2026 – Mar 31, 2027](/media/scheduling/schedule/edit-schedule-template-5.png)

## Expected Outcome

- Care shows "Schedule template updated successfully".
- If you made a public template private, its existing appointments stay. Patients can no longer book new appointments in it through self-service.
