# Add or remove a session in a schedule template

## Overview

<video src="/media/scheduling/schedule/add-or-remove-schedule-session.mp4" poster="/media/scheduling/schedule/add-or-remove-schedule-session.poster.png" controls width="720">
  <track kind="captions" src="/media/scheduling/schedule/add-or-remove-schedule-session.vtt" srcLang="en" label="English" default />
</video>

This flow describes how to add a session to a [schedule template](../../../concepts/scheduling/schedule.mdx), or remove a session from it, in Care. A session is a block of time on chosen weekdays that Care divides into slots for appointments.

## Pre-requisites

- You are a member of the facility.
- A schedule template is created for the practitioner, location or healthcare service. See [Create a schedule template](./create-schedule-template.mdx).
- If you remove a session, no future slot of that session has an appointment. If one has, cancel that appointment or reschedule it to a slot of another session first.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can Create on Schedule | Lets you add and remove sessions. You must hold it in the place given below for the resource. By default, the Admin (facility role), Staff, Facility Admin, Doctor and Nurse roles hold it. |
| Can list schedule on Object | Lets you open the schedule page and the template. Care checks it in the same place as Can Create on Schedule. For a practitioner, Care shows the **Availability** tab only if you hold it in a department or team of the facility, or in its Administration organization. By default, the Admin, Staff, Facility Admin, Doctor, Nurse and Administrator roles hold it. |
| Can Read Healthcare Service | Lets you open **Services** and a service, on the way to the schedule of a location or a healthcare service. A role in any organization of the facility counts. By default, the Facility Admin, Administrator, Admin, Staff, Doctor, Nurse, Volunteer and Pharmacist roles hold it. |

Care accepts Can Create on Schedule and Can list schedule on Object only in these places:

- For a practitioner: the facility's Administration organization, a department or team that the practitioner belongs to, or a parent of it.
- For a location: a department linked to the location or to its parent location, a parent of that department, or the facility's Administration organization.
- For a healthcare service with a managing organization: that organization or a parent of it. The Administration organization does not count.
- For a healthcare service without a managing organization: only the facility's Administration organization.

Only roles that you hold in the facility's organizations count. A role in a governance organization above the facility does not count.

Care shows the pencil icon on a template if you hold Can Create on Schedule in the facility. A role in any department or team, or in the Administration organization, counts for this. Care saves your change only if you hold the permission in the place given above. If Care refuses the change, ask your administrator for Can Create on Schedule in that place.

## Steps

### 1. Open the schedule

Each practitioner, location and healthcare service has its own schedule page. Open it in one of these ways:

- For a practitioner: in the facility sidebar, select **Users**. On the user's card, select **See Details**. Then select the **Availability** tab.
- For your own schedule: open the account menu and select **Profile**. Then select the **Availability** tab.
- For a location: in the facility sidebar, select **Services**, then a service. On a location card, select **View appointments**. This link shows for services that are not a store, a pharmacy or a lab. In the location sidebar, under **Scheduling**, select **Schedule**.
- For a healthcare service: in the facility sidebar, select **Services**, then the service. In the service sidebar, under **Scheduling**, select **Schedule**.

![The schedule page of the healthcare service General Medicine OP, with Schedule outlined under Scheduling in the service sidebar](/media/scheduling/schedule/add-or-remove-schedule-session-1.png)

Care can refuse to load the page and show "You do not have permission to update schedule". This means that you do not hold Can list schedule on Object in the place for this resource. Ask your administrator for it.

The page opens on the **Schedule** tab. It lists the schedule templates that cover the month shown on the calendar.

### 2. Open the template

On the template card, select the pencil icon. The **Edit Schedule Template** sheet opens.

Below the template details, the sheet lists the sessions under **Availabilities**. Each session shows its **Slot Configuration** and its **Session Capacity**. If the template has no session, the sheet shows "No availabilities yet".

![The Saturday OP Session card outlined under Availabilities in the Edit Schedule Template sheet, with its Slot Configuration, Session Capacity and Saturday 9 AM - 11 AM](/media/scheduling/schedule/add-or-remove-schedule-session-2.png)

### 3. Remove a session

If you only want to add a session, go to step 4.

You cannot change a session after it is saved. To change a session, remove the old session first, then add the new one. Care refuses a new session that overlaps a session that is still in the template.

On the session that you want to remove, select the trash icon. The icon has no text.

Care asks "Are you sure?" and warns "This will permanently remove the session and cannot be undone". Select **Delete**.

![The Are you sure? dialog with the warning This will permanently remove the session and cannot be undone, and the Delete button outlined](/media/scheduling/schedule/add-or-remove-schedule-session-3.png)

Care shows "Schedule availability deleted successfully".

If a future slot of the session has an appointment, Care does not remove the session. The message is "Cannot delete availability as there are future bookings associated with it".

### 4. Start a new session

Select **Add another session**. The **New Session** form opens.

### 5. Enter the session details

| Components | What it captures |
| --- | --- |
| **Session Title** | A name for the session. |
| **Start Time** and **End Time** | When the session starts and ends. The start time must be earlier than the end time. |
| **Auto-fill slot duration** | Optional. Turn it on and enter the **Number of slots:**. Care then calculates the slot duration from the length of the session. |
| **Slot duration (mins.)** | The length of each slot, in whole minutes. The length of the session must be a whole multiple of it. |
| **Patients per Slot** | How many patients can book one slot. Enter 1 or more. |
| **Weekdays** | The weekdays on which this session runs. The new session has its own weekdays. |
| **Remarks** | Optional notes about the session. |

![The New Session form outlined below No availabilities yet, filled in as Saturday OP Session from 09:00 AM to 12:00 PM with 15-minute slots, 1 patient per slot and Saturday selected](/media/scheduling/schedule/add-or-remove-schedule-session-4.png)

The new session must not overlap another session of the template on the same weekday. A session that starts when another session ends also counts as an overlap.

A session can hold at most 30 slots on a day, unless your deployment sets a different limit.

### 6. Create the session

Select **Create**. Care shows "Availability created successfully".

![The message Availability created successfully, with the new Saturday OP Session card outlined under Availabilities: 12 slots, Saturday 9 AM - 12 PM](/media/scheduling/schedule/add-or-remove-schedule-session-5.png)

## Expected Outcome

- A removed session and its slots are deleted.
- Care offers slots from a new session on its weekdays, on the days that the template's valid period covers.
