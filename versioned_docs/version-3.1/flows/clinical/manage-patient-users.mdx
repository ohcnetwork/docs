# Manage patient users

This flow walks through assigning a user, such as a volunteer, to a **patient** in Care. The assigned user supports the patient in the field, separate from the patient's clinical encounters.

:::info Prerequisite
Read [Patient](../../concepts/clinical/patient) to understand what Volunteer Contact captures.
:::

## Before you start

- The patient is registered in Care.
- The user that you want to assign has an account in Care.
- You have the **Can Update a Patient's data** permission.

## Steps

### 1. Open the patient's profile

Open the profile of the patient that you want to manage. See [View a patient's profile](./view-patient-profile.mdx).

### 2. Open the Volunteer Contact section

On the patient's profile, go to the **Volunteer Contact** section. This section lists the users that are assigned to the patient.

### 3. Search for the user that you want to assign

Enter the name or the username of the user in the search box. Care shows the helper text "Search for a user and assign a role to add them to the patient."

### 4. Select the user and assign a role

Select the user from the search results. Assign a role to the user. Care adds the user to the patient with that role.

### 5. Remove an assigned user

Do this step only when you want to remove access.

Select an assigned user in the **Volunteer Contact** section. Remove the access of that user from the patient.

## Expected outcome

- The **Volunteer Contact** section shows the assigned user together with the role that you gave.
- The assigned user can support the patient in the field.
- When you remove a user, the **Volunteer Contact** section no longer shows that user.
