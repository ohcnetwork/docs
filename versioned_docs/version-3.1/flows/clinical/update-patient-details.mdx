# Update patient details

This flow walks through updating the details of a **patient** in Care. You edit the details from the patient's profile.

:::info Prerequisite
Read [Patient](../../concepts/clinical/patient) to understand what a patient record contains.
:::

## Before you start

- The patient is registered in Care.
- You can open the patient's profile.
- You have the **Can Update a Patient's data** permission.

To edit the "General Info" and "Additional Details" sections, you normally need this permission on that patient. Some deployments enable broader edit access, where a user with the permission updates any patient's record without a direct association with the patient. This depends on your deployment's configuration.

## Steps

### 1. Open the patient's profile

Open the profile of the patient that you want to update. See [View a patient's profile](./view-patient-profile.mdx).

### 2. Select Edit

Go to the "General Info" section or the "Additional Details" section. Select the Edit action on that section. Care opens the registration form with the current details of the patient.

### 3. Update the details

Change the details that you want to update. You can update these fields:

| Component | What it captures |
| --- | --- |
| Name | The name of the patient. |
| Gender | The gender of the patient. |
| Phone Number | The primary contact number of the patient. |
| Emergency Phone Number | The contact number for emergencies. |
| Date of birth or Age | The date of birth of the patient, or the age. |
| Blood Group | The blood group of the patient. |
| Address | The current address of the patient. |
| Permanent Address | The permanent address of the patient. |
| PIN Code | The postal code of the address. |
| Geo Organization | The administrative area of the patient. |
| Is Deceased | The deceased status of the patient, with the date and time. |

The form uses the same fields and validation rules as registration. For the details of each field, see [Register a patient](./register-patient.mdx).

To record the death of a patient, see [Mark a patient as deceased](./mark-patient-deceased.mdx).

If you leave the form with unsaved changes, Care shows a warning first.

### 4. Save the changes

Save the form. Care shows a success message and returns you to the patient's profile.

## Expected outcome

- Care saves the new details of the patient.
- Care shows a success message.
- Care shows the patient's profile with the new details.
