# Search for a patient

## Overview

This flow describes how to search for an existing [patient](../../../concepts/clinical/patient) in Care. Search for the patient first, before you register a new patient. This prevents duplicate patient records.

## Pre-requisites

- You are a member of the facility where you search for the patient.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can list patients | Lets you search for patients and see the search results. |

## Steps

### 1. Open the search page

1. Open the facility.
2. Select **Patients**.
3. Select **Search patients**.

The page shows the helper text "Search for existing patients using their phone number or create a new patient record". If you can only search for patients, the page shows the helper text "Search for existing patients using their phone number".

### 2. Enter the search details

Search by one of these methods:

| Search method | What it captures |
| --- | --- |
| Identifier | The patient's phone number, or another identifier type that your deployment configures. |
| Encounter details | The patient name, or another identifier that belongs to an encounter. |

Note: Which identifier types you can search on depends on your deployment's configuration.

### 3. Read the results

The results show in a table with these columns:

| Column | What it shows |
| --- | --- |
| Name | The patient's name. |
| Phone number | The patient's phone number. |
| Gender | The patient's gender. |
| Actions | The actions that you can do on the result. |

Care shows limited information for a partial match. This protects the patient's privacy.

### 4. Verify 

If date of birth validation is added to verify patient's identity. The page shows the message "Please enter the patient's year of birth to verify their identity."

1. Enter the patient's year of birth.
2.Verify

If no additiona verification is configured, the select the patient to access Patients Home page 

### 5. Continue when there is no result

If Care finds no patient, the page shows a "no patient found" message. If you have the permission to register patients, the page offers an option to register a new patient. See [Register a patient](./register-patient.mdx).

Note: If you register a patient with a phone number that Care already holds, Care shows the message "Patient Records Found" with the text "It appears that there are patient records that contain the same phone number as the one you just entered." Read this warning before you create a duplicate record.

## Expected Outcome

- Care shows the patients that match your search.
- You open the patient's record from the results. See [View a patient's profile](./view-patient-profile.mdx).
- If Care finds no patient, you can register a new patient.
