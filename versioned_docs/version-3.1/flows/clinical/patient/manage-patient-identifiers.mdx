# Manage a patient's identifiers

## Overview

This flow describes how to enter, change and see the identifiers of a [patient](../../../concepts/clinical/patient) in Care. The registration form and the update form show the deployment-wide identifiers: the identifiers that are set up for every facility of your deployment.

## Pre-requisites

- A superuser has set up identifiers for your deployment, and they are active.
- If you enter identifiers for a new patient, you can register patients. See [Register a patient](./register-patient.mdx).
- If you change the identifiers of a registered patient, you can update that patient. See [Update a patient's details](./update-patient-details.mdx).
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can Create Patient | Enter identifiers when you register a patient. You can hold this permission in any department or team of a facility, in a government organization, or in a responsibility. By default, the Staff, Doctor, Nurse, Administrator and Facility Admin roles hold this permission, and so does the Admin role of a responsibility. |
| Can Update a Patient's data | Change the identifiers of a registered patient. Care shows **Edit** in **General Info** only if you hold it. You need this permission through a role on the patient. By default, the Staff, Doctor, Nurse, Administrator and Facility Admin roles hold this permission. |
| Can view clinical data about patients | Steps 2 and 4: open the patient's profile. You need it through a role on the patient. By default, the Staff, Doctor, Nurse and Facility Admin roles hold it. |
| Can list patients | Steps 2 and 4: open the patient's profile, in place of Can view clinical data about patients. You need it in a government organization that covers the patient. If you are assigned to the patient on the **Users** tab, you need neither of these two permissions. By default, the Staff, Doctor, Nurse, Volunteer and Administrator roles hold it. The Pharmacist and Facility Admin roles hold it too, but Care does not offer them for a government organization. |
| Can Read Tag Config | Steps 2 and 4: open the profile inside a facility. Hold it in the facility's Administration department or in one of its departments or teams. A role in a government organization does not count. By default, the Facility Admin, Administrator, Staff, Doctor, Nurse, Volunteer and Pharmacist roles hold it. |

To see **Add New Patient** at the top of **Search patients**, you need Can Create Patient in this facility. [Register a patient](./register-patient.mdx) lists the other permissions on that path.

## Steps

### 1. Enter identifiers when you register a patient

Open the **Register New Patient** form. See [Register a patient](./register-patient.mdx).

Each identifier field has the name of the identifier as its label. The description of the identifier shows under the label.

The identifier fields are in these places:

| Place | Identifiers |
| --- | --- |
| **Patient Basics** | The required identifiers. Care marks each one as required. |
| **Additional Details** | The optional identifiers, with no required mark. |
| End of **Additional Details** | The identifiers that Care generates. You cannot type in these fields. They show "Auto-generated on Save". |

Enter a value for each required identifier. If you leave one empty, Care shows "This field is required".

Enter a value for each optional identifier that you know.

Select **Register Patient**.

After Care registers the patient, it fills the values of the generated identifiers.

Care does not fill a generated identifier when you update a patient. A patient who was registered before the identifier was set up stays without a value for it.

Note: The forms show only deployment-wide identifiers. An identifier that one facility sets up does not show on these forms.

Note: Care can also keep identifiers itself, from the patient's phone number and name. The forms and the profile do not show these identifiers.

### 2. Change the identifiers of a registered patient

Open the patient's profile inside the facility. In **General Info**, select **Edit**. See [Update a patient's details](./update-patient-details.mdx).

The identifier fields show the patient's current values.

Change a value, or enter a value for an identifier that is empty.

To remove an optional identifier from the patient, clear its field.

You cannot clear a required identifier. If you leave it empty, Care shows "This field is required".

Select **Update**.

![The Hospital Card Number field outlined on the update form, with a value typed in it](/media/clinical/patient/manage-patient-identifiers-2.png)

![The General Info section of the patient's profile with the Edit button outlined](/media/clinical/patient/manage-patient-identifiers-1.png)

### 3. Correct a value that Care refuses

When you save either form, Care checks each identifier value:

- If a required identifier is empty, the form shows "This field is required" and does not save.
- A unique identifier cannot have the same value as another patient. Otherwise Care shows a message that ends with "is not unique".
- A value must match the set format of its identifier. Otherwise Care shows a message that ends with "is not valid".

Correct the value and save again.

### 4. See the patient's identifiers

Open the patient's profile. See [View a patient's profile](./view-patient-profile.mdx).

On the **Demography** tab, go to the **Identifiers** section. It shows the name and the value of each identifier.

The **Identifiers** section has no **Edit**. To change a value, use the update form, as in step 2.

Note: Registering a patient does not by itself let you open the patient's profile. You need a role on the patient, for example through an encounter.

The header of the profile also shows each identifier, with its name and value.

![The Identifiers section of the Demography tab outlined, showing Hospital Card Number and its value](/media/clinical/patient/manage-patient-identifiers-3.png)

## Expected Outcome

- When you open the patient's profile, its **Identifiers** section shows the values that you entered.
- After registration, the generated identifiers have values.
- If you cleared an identifier field on the update form, the patient no longer has that identifier.
