# Register a patient

## Overview

This flow describes how to register a new [patient](../../../concepts/clinical/patient) in Care. Use it when a person comes to your facility and Care holds no record for that person.

## Pre-requisites

- You are signed in to Care.
- You searched for the patient first, and Care found no existing record. See [Search for a patient](./search-patient.mdx).
- You have the patient's personal details, contact number, and identity documents.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can Create Patient | Lets you register a new patient in Care. |

## Steps

### 1. Open the registration form

Open the Patient Registration page.

You can also open the form from the search results. If the search finds no record, Care offers to register a new patient.

### 2. Enter the personal details

Complete the fields in the table below.

| Component | What it captures |
| --- | --- |
| Name | The full name of the patient. This field is required. |
| Phone Number | The primary contact number of the patient. This field is required. Care validates the format. |
| Emergency Phone Number | The contact number for emergencies. This field is optional. |
| Same as phone number | Copies the phone number into the emergency number. Care turns this toggle on by default. |
| Gender | The gender of the patient. This field is required. Select Male, Female, Non-binary, or Transgender. |
| Date of birth or Age | The age details of the patient. This field is required. |
| Select Blood Group | The blood group of the patient. This field is optional. |
| Patient Tags | Labels that group the patient. This field is optional. |
| Address | The current address of the patient. |
| Permanent Address | The permanent address of the patient. |
| Same as address | Copies the current address into the permanent address. Care turns this toggle on by default. |
| PIN Code | The postal code of the address. This field is optional. |
| Geo Organization | The government administrative area of the patient. This field is required. |

Use the toggle to choose between Date of birth and Age.

If you enter the date of birth, do not enter a future date.

If you enter the age, Care calculates the year of birth.

For Geo Organization, select each level in order.

Note: Deployment can configure fields which are mandatory and non mandatory. Deceased status should be marked only for patients who are brought dead.

### 4. Enter the patient identifiers

Enter the identifiers that your facility configures, for example a national identity number.

Identifiers that are configured as auto generated gets generated once patient registration is completed 

For more details, see [Manage patient identifiers](./manage-patient-identifiers.mdx).

### 5. Save the patient

Save the form.

## Expected Outcome

- Care creates the patient record with the details you entered.
- Care opens the profile of the new patient. See [View a patient's profile](./view-patient-profile.mdx).
- You can now search for the patient by name or phone number.
