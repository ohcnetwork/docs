# Manage patient tags

## Overview

This flow describes how to add and remove tags on a [patient](../../../concepts/clinical/patient) in Care. Tags are labels that mark or categorize a patient, separate from clinical data.

## Pre-requisites

- The patient is registered in Care.
- You can access the patient's profile.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can Update a Patient's data | Add and remove tags on an existing patient. |

## Steps

### 1. Open the patient's profile

Open the profile of the patient that you want to tag. See [View a patient's profile](./view-patient-profile.mdx).

### 2. Find the Patient Tags section

Go to the **Patient Tags** section. This section shows the current tags of the patient.

### 3. Open the tag picker

Select **Edit** in the **Patient Tags** section. Care opens the tag picker.

### 4. Add or remove tags

Select a tag in the picker to add it to the patient. Remove a tag to take it off the patient.

### 5. Save the tags

Save your changes. Care updates the tags of the patient.

Note: You can also add tags when you register a new patient. See [Register a patient](./register-patient.mdx).

## Expected Outcome

- The **Patient Tags** section shows the updated tags of the patient.
