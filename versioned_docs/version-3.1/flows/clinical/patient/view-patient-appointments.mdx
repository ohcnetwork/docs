# View a patient's appointments and tokens

This flow walks through opening Patient Home and viewing the appointments and queue tokens of a **patient** in Care.

:::info Prerequisite
Read [Patient](../../../concepts/clinical/patient) to understand what a patient record contains.
:::

## Before you start

- The patient is registered in Care.
- You verified the patient's identity from search, or you opened the patient's profile.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| List appointments at the facility | Lets you view the patient's appointments. |
| List tokens at the facility | Lets you view the patient's queue tokens. |
| Write appointments | Lets you book an appointment for the patient. |
| Create encounters | Lets you create an encounter for the patient. |

## Steps

### 1. Open Patient Home

Verify the patient's identity from search, or open the patient's profile. Care shows Patient Home for that patient, with the patient's basic information and a set of tabs. The Encounters tab opens first.

### 2. Use the quick actions

Patient Home offers quick actions for the patient. Your permissions control which quick actions appear:

- Book an appointment for the patient.
- Create an encounter for the patient.
- Generate a queue token for the patient.

Whether the "Generate Token" quick action appears on Patient Home can also depend on your deployment's configuration.

### 3. View the patient's appointments

Open the appointments view on Patient Home. Care shows the patient's existing appointments. To narrow the list, select a facility.

### 4. View the patient's tokens

Open the tokens view on Patient Home. Care shows the patient's queue tokens. To narrow the list, select a facility.

## Expected outcome

- You see the patient's basic information on Patient Home.
- You see the patient's existing appointments, for all facilities or for one facility.
- You see the patient's queue tokens, for all facilities or for one facility.
