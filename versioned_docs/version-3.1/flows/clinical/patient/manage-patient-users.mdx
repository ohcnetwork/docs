# Manage patient users

## Overview

This flow describes how to assign a user to a [patient](../../../concepts/clinical/patient) in Care. The assigned user supports the patient in the field, separate from the patient's clinical encounters.

## Pre-requisites

- The patient is registered in Care.
- The user that you want to assign has an account in Care.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can Update a Patient's data | Lets you assign a user to the patient and remove an assigned user. |

## Steps

### 1. Open the patient's profile

Open the profile of the patient that you want to manage. For the full steps, see [View a patient's profile](./view-patient-profile.mdx).

### 2. Open the User section

On the patient's profile, go to the **Users** section. This section lists the users that are assigned to the patient.

### 3. Search for the user that you want to assign

Enter the name or the username of the user in the search box. Care shows the helper text "Search for a user and assign a role to add them to the patient."

### 4. Select the user and assign a role

Select the user from the search results. Assign a role to the user. Care adds the user to the patient with that role.

### 5. Remove an assigned user

Note: Do this step only when you want to remove access.

Select an assigned user in the **Users** section. Remove the access of that user from the patient.

## Expected Outcome

- The **Users** section shows the assigned user together with the role that you gave.
- The assigned user can support the patient in the field.
- When you remove a user, the **Users** section no longer shows that user.
