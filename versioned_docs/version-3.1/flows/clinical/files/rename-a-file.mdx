# Rename a file

## Overview

<video src="/media/clinical/files/rename-a-file.mp4" poster="/media/clinical/files/rename-a-file.poster.png" controls width="720">
  <track kind="captions" src="/media/clinical/files/rename-a-file.vtt" srcLang="en" label="English" default />
</video>

This flow describes how to change the name of a [file](../../../concepts/clinical/files.mdx) on the **Files** tab of a patient or of an encounter.

## Pre-requisites

- The file is on the **Files** tab of the patient or of the encounter. Patient files and encounter files are in separate lists.
- The file is not archived. An archived file has an **Archived** badge and no **More Actions** button. You cannot rename it on the **Files** tab.
- If the file is on an encounter, you opened the encounter from a facility, not from an organization.
- If the file is on an encounter, you look at the encounter that you opened. If you select another encounter of the patient on that page, Care does not show **Rename**.
- If the file is on an encounter, the encounter is not closed. Care treats an encounter as closed when its status is Completed, Cancelled, Entered in error or Discontinued.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can Update a Patient's data | Rename patient files. Care shows **Rename** on the patient's **Files** tab only with this permission. Hold it through [a role on the patient](../../../concepts/clinical/files.mdx#permissions). By default, Staff, Doctor, Nurse, Administrator, Admin and Facility Admin hold it. |
| Update Encounter related clinical data | Rename encounter files. Hold it in a [department](../../../concepts/facility/department.mdx) of the encounter or of its current location. Nobody can rename the files of a closed encounter. By default, Admin, Doctor, Nurse and Facility Admin hold it. |
| Update Encounter non clinical | Care shows **Rename** on the encounter's **Files** tab only with this permission. Hold it through a role on the encounter. By default, Admin, Doctor, Nurse and Facility Admin hold it. |
| Can view clinical data about patients | Shows the patient's **Files** tab and lists the patient files. Hold it through [a role on the patient](../../../concepts/clinical/files.mdx#permissions). By default, Staff, Doctor, Nurse, Admin and Facility Admin hold it. |
| Can Read encounter related clinical data | Shows the encounter's **Files** tab and lists the encounter files. Hold it in a department of the encounter or of its current location. By default, Admin, Doctor, Nurse and Facility Admin hold it. |

Note: By default, the Administrator role holds "Can Update a Patient's data" but not "Can view clinical data about patients". So a user who has only the Administrator role cannot open the patient's **Files** tab, and cannot rename files there.

## Steps

### 1. Open the Files tab

Open the patient or the encounter that the file belongs to.

Select the **Files** tab. In an encounter, you can also press `g` and then `f`.

Make sure that the **Files** sub-tab is selected. Care selects it when you open the tab.

For help to find the file in the list, see [Find a file](./find-a-file.mdx).

![The row of Scan 0412.pdf in the Files list](/media/clinical/files/rename-a-file-1.png)

### 2. Open the More Actions menu

In the row of the file, select **More Actions**. This is the button with three vertical dots.

The menu shows **Download**. If you can change the files here, the menu also shows **Rename** and **Archive**.

If the menu shows only **Download**, you cannot change the files here. Check the pre-requisites and the permissions on this page.

![The More Actions menu of a file with Download, Rename and Archive](/media/clinical/files/rename-a-file-2.png)

### 3. Select Rename

Select **Rename**. Care opens the **Rename File** dialog.

The **Enter the file name** box shows the current name of the file without its extension.

![The Rename File dialog with the current name Scan 0412 in the Enter the file name box](/media/clinical/files/rename-a-file-3.png)

### 4. Enter the new name

Change the name in the **Enter the file name** box.

Do not add the extension. Care keeps the extension and shows it after the name in the list.

If the box is empty, you cannot select **Proceed**.

If the name has only spaces, Care shows **Please enter a name!** and does not change the name.

![The Rename File dialog with the new name Ultrasound report](/media/clinical/files/rename-a-file-4.png)

### 5. Save the new name

Select **Proceed**.

To close the dialog without a change, select **Cancel**.

![The message File name changed successfully, and Ultrasound report.pdf in the Files list](/media/clinical/files/rename-a-file-5.png)

## Expected Outcome

- Care shows **File name changed successfully**.
- Care refreshes the list. The file shows the new name, followed by its extension.
- Care changes only the name. The content of the file stays the same.
