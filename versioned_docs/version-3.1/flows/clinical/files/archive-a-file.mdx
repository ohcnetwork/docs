# Archive a file

## Overview

This flow describes how to archive a [file](../../../concepts/clinical/files.mdx) in Care. Care has no permanent delete for files. Archiving is the only way to remove a file from the active list.

Note: Archiving is irreversible. You cannot restore an archived file.

## Pre-requisites

- The file is uploaded to the patient or the encounter that you work with.
- You know the reason for the archive. Care asks you to type the reason.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Write access to the patient or the encounter that the file belongs to | Lets you archive the file. |

## Steps

### 1. Open the file action menu

Go to the file that you want to archive.

Click the **...** menu for the file.

### 2. Select Archive

Select **Archive**.

Care opens a confirmation dialog. The dialog warns you that this action is irreversible.

### 3. Enter the reason

Enter the reason for the archive in the text box.

Confirm the archive.

## Expected Outcome

- Care greys out the file in the list and adds an **Archived** badge.
- Care hides the file from the default list. To see the file again, set the filter on the **Files** tab to **Archived**.
- For an archived file, the **View** option opens the details dialog. The dialog shows who uploaded the file and when. The dialog also shows who archived the file, when, and why.
