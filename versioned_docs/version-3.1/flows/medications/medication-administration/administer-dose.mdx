# Administer a dose

## Overview

<video src="/media/medications/medication-administration/administer-dose.mp4" poster="/media/medications/medication-administration/administer-dose.poster.png" controls width="720">
  <track kind="captions" src="/media/medications/medication-administration/administer-dose.vtt" srcLang="en" label="English" default />
</video>

This flow describes how to record a dose of a prescribed medicine that staff gave to a patient during an encounter. Care saves the dose as a [medicine administration](../../../concepts/medications/medication-administration.mdx).

## Pre-requisites

- The medicine is prescribed on the patient's encounter and is active. See [Prescribe medicines](../medication-request/prescribe-medication.mdx).
- The encounter is open. Care does not let you record a dose when the encounter is Completed, Cancelled, Discontinued, or Entered in error.
- You opened the encounter from the facility. An encounter opened from an organization is read-only.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Update Encounter related clinical data | Lets you save the dose. You must hold it in one of the encounter's departments or in a department of its current location. By default, the Doctor, Nurse and Facility Admin roles hold this permission. |
| Can view clinical data about patients | Lets you open the **Medications** tab and read the chart, when you hold it for the patient. You need this permission or the next one. By default, the Staff, Doctor, Nurse and Facility Admin roles hold this permission. |
| Can Read encounter related clinical data | Gives the same access for this encounter only, when you hold it in one of the encounter's departments or in a department of its current location. By default, the Doctor, Nurse and Facility Admin roles hold this permission. |

By default, the Staff role can read the chart but cannot save a dose.

## Steps

### 1. Open the Medicine Administration sub-tab

1. Open the encounter.
2. Select the **Medications** tab.
3. Select the **Medicine Administration** sub-tab.

Note: Press `g` then `m` to go to the **Medications** tab.

Care shows the medicine administration chart. Each row is one medicine, and the columns are six-hour time slots.

![The Medicine Administration sub-tab outlined, with the grid of medicines against six-hour time slots](/media/medications/medication-administration/administer-dose-1.png)

### 2. Find the medicine

Care opens the sub-tab on **Medications**.

To narrow the list, enter the name of the medicine in the **Search Medication** box.

Note: To record a nutritional product, select **Nutrition**. The steps are the same, and the buttons read **Record Intake**.

![The Search Medication box outlined, with Amox typed and only Amoxicillin left in the grid](/media/medications/medication-administration/administer-dose-2.png)

### 3. Open the administration dialog

In the current time slot of the medicine's row, select **Administer**. Care opens the **Administer Medicine** dialog.

Note: Care shows **Administer** only in the current time slot, and only for an active entry of the medicine. The time slot must also be inside the prescribed period.

Note: If the medicine was prescribed more than once, the row groups those entries. You can expand the row. Each active entry then has its own **Administer** button.

Note: To record doses of several medicines at once, select **Administer Medicine** at the top of the sub-tab. In the **Administer Medicines** panel, select the checkbox of each medicine that you gave. Complete the fields of each medicine as in steps 4 to 7. Then select **Administer Medicines**. The button shows the number of medicines that you selected. Care saves all of these doses, or none of them.

![The Administer button in the current time slot of the Amoxicillin row outlined](/media/medications/medication-administration/administer-dose-3.png)

### 4. Check the entry and the dosage

If you selected **Administer** on the row of the medicine, Care lists its entries under **Prescriptions in Group**. Care shows this list also when the medicine has only one entry.

Care selects the latest active entry. If the dose is for another entry, select that entry in the list.

If all dosage instructions of the entry have the same dose, Care shows the dosage, frequency, route and duration.

If the entry has dosage instructions with different doses, select the dose that you gave under **Select Dosage Instruction**.

![The Administer Medicine dialog with the dosage, frequency, route and duration from the prescription outlined](/media/medications/medication-administration/administer-dose-4.png)

### 5. Set the status

Care sets **Status** to **Completed**.

If staff did not complete the dose, select a different status. For example, select **Not Done**, **Stopped**, **On Hold**, or **In Progress**.

Note: If you select **In Progress** or **Not Done**, Care clears the end time.

![The Status field of the Administer Medicine dialog outlined, set to Completed](/media/medications/medication-administration/administer-dose-5.png)

### 6. Record the time

Care sets **Start Time** and **End Time** to the current date and time.

To record a dose from an earlier time, select **Yes** for **Is this administration for a past time**? Then set **Start Time** and **End Time**.

Care does not accept a start time or an end time in the future. The end time cannot be before the start time.

If the status is **Completed**, the dose must have an end time before you can save it.

Note: Care warns you when the start time is outside the prescribed period. The warning reads "This administration is outside the prescribed schedule." You can still save the dose.

![The Start Time fields of the Administer Medicine dialog outlined, with No selected for a past time](/media/medications/medication-administration/administer-dose-6.png)

### 7. Add a note

To record more detail, enter text in **Administration Notes**. This field is optional.

![The Administration Notes box outlined, with a note about the dose](/media/medications/medication-administration/administer-dose-7.png)

### 8. Save the dose

Select **Administer Medicine**.

![The new dose shown as a chip with its time in the current slot of the Amoxicillin row, outlined, and the message Medicine Administration saved](/media/medications/medication-administration/administer-dose-8.png)

## Expected Outcome

- Care shows the message "Medicine Administration saved".
- Care shows the dose in its time slot as a button with the time of the dose.
- The colour of the button shows the status: green for Completed, yellow for In Progress, and red for all other statuses.
- The medicine's row shows "Last administered" with the time since the last dose.
