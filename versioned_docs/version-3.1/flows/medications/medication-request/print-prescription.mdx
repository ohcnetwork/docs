# Print a prescription

## Overview

This flow describes how to print a prescription from an encounter in Care. You can print the selected prescription, or every prescription of the encounter. See [medication request](../../../concepts/medications/medication-request.mdx).

## Pre-requisites

- You open the encounter from your facility. Care shows the print buttons only on an encounter that you open from a facility.
- The prescription that you print has at least one medicine.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can Read encounter | Load each prescription on the print page. You must hold it in one of the encounter's departments, or in a department of the encounter's current location. By default, the Doctor, Nurse and Facility Admin roles hold this permission. The Staff role does not, so Staff cannot print a prescription. |
| Can view clinical data about patients | Open the encounter, see the **Medications** tab, and list the prescriptions to print. You need this permission for the patient, or the next permission. By default, the Staff, Doctor, Nurse and Facility Admin roles hold this permission. |
| Can Read encounter related clinical data | Gives the same access as the permission above, when you hold it in one of the encounter's departments, or in a department of the encounter's current location. By default, the Doctor, Nurse and Facility Admin roles hold this permission. |
| Pharmacist in Care | Another way to list and load the prescriptions, held in any department of the facility. It does not show the **Medications** tab on its own. By default, the Facility Admin and Pharmacist roles hold this permission. |

## Steps

### 1. Open the prescriptions

1. Open the encounter. Select the **Medications** tab.
2. Stay on the **Prescriptions** sub-tab.

For more about this screen, see [View prescriptions and medicines for an encounter](./view-encounter-medications.mdx).

![The Prescriptions sub-tab outlined on the Medications tab, with All Prescriptions selected](/media/medications/medication-request/print-prescription-1.png)

### 2. Select what to print

Select one of these options:

- To print one prescription, select the prescription. Then select **Print**.
- To print every prescription of the encounter, select **Print All Prescriptions**.

Care shows **Print All Prescriptions** whether or not you selected a prescription.

Note: Care disables **Print** when the selected prescription has no medicines.

Note: Care disables **Print All Prescriptions** when the panel shows no medicines.

![One prescription selected, with its Print button outlined next to Edit and Print All Prescriptions](/media/medications/medication-request/print-prescription-2.png)

### 3. Print the prescription

Care opens a print page. Select **Print**.

On a phone or tablet that can share a PDF, the button is **Share**. Select **Share** to share the PDF.

Note: Press `p` on the print page to print.

![The print page of the prescription, with the facility, the patient details and the medicine instructions, and the Print button outlined](/media/medications/medication-request/print-prescription-3.png)

## Expected Outcome

- Care shows a print preview of the selected prescription, or of every prescription of the encounter.
- If none of the prescriptions has medicines, the print page shows "No medications found for this encounter."
- If the encounter has no prescriptions, the print page for all prescriptions shows "No prescriptions found".
