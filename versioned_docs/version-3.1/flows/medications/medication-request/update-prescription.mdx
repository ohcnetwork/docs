# Edit a prescription

## Overview

  <track kind="captions" src="/media/medications/medication-request/update-prescription.vtt" srcLang="en" label="English" default />

This flow describes how to edit a saved prescription in Care. You can change the note of a medicine, or remove a medicine that was entered by mistake. You cannot add medicines to a saved prescription. See [medication request](../../../concepts/medications/medication-request.mdx).

## Pre-requisites

- You open the encounter from your facility. Care shows an encounter that you open from an organization as read-only.
- The status of the encounter is not Completed, Cancelled, Discontinued or Entered in error.
- If you view an earlier encounter inside the encounter page, go back to the encounter that you opened. Care lets you edit only in that encounter.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Update Encounter related clinical data | Save the changes. You must hold it in one of the encounter's departments, or in a department of the encounter's current location. By default, the Doctor, Nurse and Facility Admin roles hold this permission. |
| Can Read encounter | Open the prescription and load its medicines into the form. You must hold it in one of the encounter's departments, or in a department of the encounter's current location. By default, the Doctor, Nurse and Facility Admin roles hold this permission. The Staff role does not. |
| Can view clinical data about patients | Open the encounter, see the **Medications** tab, and list the prescriptions. You need this permission for the patient, or the next permission. By default, the Staff, Doctor, Nurse and Facility Admin roles hold this permission. |
| Can Read encounter related clinical data | Gives the same access as the permission above, when you hold it in one of the encounter's departments, or in a department of the encounter's current location. By default, the Doctor, Nurse and Facility Admin roles hold this permission. |

## Steps

### 1. Select the prescription

1. Open the encounter. Select the **Medications** tab.
2. On the **Prescriptions** sub-tab, select the prescription that you want to edit.

For more about this screen, see [View prescriptions and medicines for an encounter](./view-encounter-medications.mdx).

![A prescription outlined in the list on the Prescriptions sub-tab](/media/medications/medication-request/update-prescription-1.png)

### 2. Open the form

Select **Edit**.

Care opens the "Medication Request" form with the medicines of the prescription.

The note of the prescription is read-only on this form. If the prescription has no note, Care shows "No notes available".

Note: If the prescription has more than 100 medicines, Care loads 100 of them. Care shows a warning that some older medicines may not show.

Note: The form does not show the medicine picker, **Medication History** or **Templates**. To prescribe more medicines, make a new prescription. See [Prescribe medicines](./prescribe-medication.mdx).

![The Edit button of the selected prescription outlined](/media/medications/medication-request/update-prescription-2.png)

### 3. Change the note of a medicine

The saved medicines are read-only, except for their notes.

Enter or change the text in the note field of the medicine.

Note: On a large screen, Care disables the whole row of an inactive medicine, including its note.

![The Medication Request form opened to edit, with the Note field of a saved medicine outlined and the text Take after food](/media/medications/medication-request/update-prescription-3.png)

### 4. Remove a medicine entered by mistake

Start the removal:

- On a large screen, select **Medication actions** at the end of the row. Then select **Remove**.
- On a small screen, expand the medicine card. Then select the remove button.

In **Remove Medication**, select **Remove**.

Care does not delete the medicine. Care sets its status to Entered in Error and keeps it on the prescription.

Note: On a small screen, the remove button is disabled for an inactive medicine.

Note: **Remove** marks a medicine as Entered in Error. To end a medicine with the status Ended, see [Stop a medicine](./stop-a-medicine.mdx).

![The Remove Medication dialog asking to confirm the removal of Ibuprofen, with the Remove button outlined](/media/medications/medication-request/update-prescription-4.png)

![The removed medicine, Ibuprofen, greyed out in the form and outlined](/media/medications/medication-request/update-prescription-5.png)

### 5. Save the changes

Select **Save Changes**.

Note: Press `Shift+Enter` to save the form.

![The Medication Request form with the Save Changes button outlined](/media/medications/medication-request/update-prescription-6.png)

![The encounter Overview tab after the save, with the message Questionnaire submitted successfully outlined](/media/medications/medication-request/update-prescription-7.png)

## Expected Outcome

- Care shows "Questionnaire submitted successfully".
- Care opens the **Overview** tab of the encounter.
- Care saves only the medicines that you changed.
- A note that you changed shows under the instructions of the medicine on the **Prescriptions** sub-tab.
- A medicine that you removed has the status Entered in Error. Care hides it with the other inactive medicines, and strikes it through when you show them.
