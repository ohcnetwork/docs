# View a facility

## Overview

This flow describes how to browse [facilities](../../concepts/facility/facility.mdx) in Care and open one to
see its details. Care gives you two ways to do this. You can browse the public
directory without a sign-in. You can also open a facility from within an organization
after you sign in.

## Pre-requisites

- If you use the public directory, your deployment makes the public Facilities page
  available. If your deployment turns the page off, Care sends you to the sign-in page.
- If you use admin view, you sign in to Care.
- If you use the signed-in view, you can open the organization that contains the
  facility. To add a facility, see [Create a facility](./create-facility.mdx).
- You have the access listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Facility membership | You can see a facility when you belong to that facility. |
| Shared Geo Organization | You can see a facility when you share its Geo Organization. |

## Steps

Note: Steps 1 and 2 describe the public directory. Steps 3 to 5 describe the
signed-in view.

### 1. Browse the public directory

Go to the public **Facilities** page. Pick an organization to filter the list. Care
shows the matching facilities as cards. Browse the cards to find the facility that
you want.

### 2. Open a facility from the public directory

Select a facility card. Care opens the public page for that facility. The page shows
the information in the table below.

| Components | What it shows |
| --- | --- |
| Facility Name | The name of the facility. |
| Address | The address of the facility. |
| Map link | A link to the location of the facility on a map. |
| Features | The features that the facility offers. |
| Description | The description of the facility. |
| Users | The users that you can book an appointment with at this facility. |

### 3. Browse facilities in admin view

Sign in to Care. Open the organization. Go to the **Facilities** section of the
organization. Care shows the facilities as cards. Each card shows the name, the type,
and the cover image of the facility. Search by name to narrow the list.

### 4. Open a facility from the organization

Select **View Facility** on the card. Care opens the facility on its Overview page.

### 5. See the full facility details

Select **Settings**. Select **General**. This page shows the information in the table
below.

| Components | What it shows |
| --- | --- |
| Facility Name | The name of the facility. |
| Facility Type | The type of the facility. |
| Address | The address of the facility. |
| Phone Number | The phone number of the facility. |
| Geo Organization | The Geo Organization that contains the facility. |
| Features | The features that the facility offers. |
| Description | The description of the facility. |

## Expected Outcome

- You find the facility in the public directory or in admin view.
- You see the details of the facility on its public page or on the General page in
  Settings.
