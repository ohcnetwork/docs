# Edit the details of a draft invoice

## Overview

This flow describes how to change the issue date, the payment terms and the note of a draft [invoice](../../../concepts/billing/invoice.mdx) in Care. To add, remove or change the items of the invoice, see [Change the items of a draft invoice](./edit-invoice-items.mdx).

## Pre-requisites

- The invoice status is Draft. Care shows **Edit Details** only for a draft invoice.
- If the invoice is locked, you have Can Manage Locked Invoice, so that you can open it.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can Write Invoice | Save the new details. Facility Admin, Staff, Doctor, Nurse and Pharmacist hold it. |
| Can Read Invoice | Open the invoice. Care also checks it when you save. Facility Admin, Administrator, Staff, Doctor, Nurse, Volunteer and Pharmacist hold it. |
| Can Manage Locked Invoice | Only to open a locked invoice. Facility Admin holds it. |

You hold each permission through a role in any organization of the facility. The roles named are the default roles.

## Steps

### 1. Open the invoice

Open the draft invoice. See [Find and open an invoice](./view-invoice.mdx).

![Care screen for step 1, Open the invoice](/media/billing/invoice/edit-invoice-1.png)

### 2. Open the details form

Select **Edit Details**.

Care opens **Edit Invoice Details**.

![Care screen for step 2, Open the details form](/media/billing/invoice/edit-invoice-2.png)

### 3. Change the details

Change the values that you need.

| Components | What it captures |
| --- | --- |
| Issue Date | The date of issue. You cannot select a date in the future. |
| Payment Terms | The conditions for payment. |
| Note | More information about the invoice. |

If the date is in the future, Care shows **Issue date cannot be in the future**.

![Care screen for step 3, Change the details](/media/billing/invoice/edit-invoice-3.png)

### 4. Save the changes

Select **Save Changes**.

The button is available only after you change a value.

![Care screen for step 4, Save the changes](/media/billing/invoice/edit-invoice-4.png)

![Care screen for step 4, Save the changes](/media/billing/invoice/edit-invoice-5.png)

## Expected Outcome

- Care shows **Invoice updated successfully**.
- The invoice shows the new details.
- The invoice status stays Draft.
