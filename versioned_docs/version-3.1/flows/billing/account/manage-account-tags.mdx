# Add or remove account tags

## Overview

This flow describes how to add tags to an [account](../../../concepts/billing/account.mdx) and remove them.

You can then filter the account list by tags.

## Pre-requisites

- The tags that you want to use are set up for the facility. See [Tag](../../../concepts/platform/tagging.mdx).
- You can open the account list or the account page. See [View an account](./view-account.mdx).
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can Update Account | Lets you save the tag changes. You must hold it in the facility. Facility Admin holds it by default. |
| Can Read Tag Config | Lets the tag picker list the tags. You must hold it in the facility. Facility Admin, Administrator, Staff, Doctor, Nurse, Volunteer, and Pharmacist hold it by default. |
| Can Read Account | Lets you see the account list and open the account page. You must hold it in the facility. Facility Admin, Administrator, Staff, Doctor, Nurse, Volunteer, and Pharmacist hold it by default. |
| Can Read Invoice | If you start from the account page, lets you see the **Invoices** tab, which the page opens first. You must hold it in the facility. Facility Admin, Administrator, Staff, Doctor, Nurse, Volunteer, and Pharmacist hold it by default. |

If you do not have Can Update Account, Care still shows the tag controls, but it does not save your changes.

## Steps

### 1. Open the tag picker

On the account page, select **Add Tags**. If the account already has tags, the button is **Manage Tags**.

Note: The **Tags** column of the account list also lets you change the tags of each account.

![Care screen for step 1, Open the tag picker](/media/billing/account/manage-account-tags-1.png)

### 2. Add or remove tags

Select the tags that you want to add to the account.

In the same tag picker, remove the tags that you do not want on the account.

![Care screen for step 2, Add or remove tags](/media/billing/account/manage-account-tags-2.png)

![Care screen for step 2, Add or remove tags](/media/billing/account/manage-account-tags-3.png)

## Expected Outcome

- Care saves the tag changes and shows **Tags updated successfully**.
- The account page and the account list show the tags of the account.
- You can find the account with the **Tags** filter of the account list.
