# Advance the billing status

## Overview

This flow describes how to move an [account](../../../concepts/billing/account.mdx) to a later Billing Status with the **Billing Status** stepper on the account page.

The Billing Status is separate from the Status of the account.

## Pre-requisites

- You can open the account page. See [View an account](./view-account.mdx).
- The account has the Status Active.
- The account does not have a closed Billing Status.
- You have the permissions listed below.

## Permissions

| Permission | Access |
| --- | --- |
| Can Update Account | Lets you select a step in the stepper, and saves the new Billing Status. You must hold it in the facility. Facility Admin holds it by default. |
| Can Read Account | Lets you open the account page. You must hold it in the facility. Facility Admin, Administrator, Staff, Doctor, Nurse, Volunteer, and Pharmacist hold it by default. |
| Can Read Invoice | Lets you see the **Invoices** tab, which the account page opens first. You must hold it in the facility. Facility Admin, Administrator, Staff, Doctor, Nurse, Volunteer, and Pharmacist hold it by default. |

## Steps

### 1. Open the account

Open the account page. See [View an account](./view-account.mdx).

### 2. Find the Billing Status stepper

Find the **Billing Status** stepper on the account page. The stepper shows the steps Open, Care Completed, Billing, and Closed.

The stepper shows the name of the current step and the next step. Point to another step to see its name.

![Care screen for step 2, Find the Billing Status stepper](/media/billing/account/advance-account-billing-status-1.png)

### 3. Select a later step

Select the step that you want to move the account to.

You can select any later step. You can skip a step, for example from Open to Billing.

You cannot select the current step or an earlier step.

If you select **Care Completed** or **Billing**, Care saves the new Billing Status at once.

If you select **Closed**, Care opens the **Close Account** dialog. To continue, see [Settle and close an account](./settle-and-close-account.mdx).

Note: To set an earlier Billing Status, edit the account. See [Edit an account](./edit-account.mdx).

![Care screen for step 3, Select a later step](/media/billing/account/advance-account-billing-status-2.png)

![Care screen for step 3, Select a later step](/media/billing/account/advance-account-billing-status-3.png)

## Expected Outcome

- Care shows **Billing status updated successfully**.
- The account has the new Billing Status.
- If the account was Open, it is no longer the default account of the patient. The next charge item that is added without a chosen account goes to another Active, Open account of the patient. If there is none, Care creates a new account. When Care creates this new account, a new billing period starts.
- While the account is Active and not closed, you can still add charge items, invoices, and payments on its page.
