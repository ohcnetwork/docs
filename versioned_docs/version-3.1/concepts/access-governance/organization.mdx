# Organisation

## Definition

An **[organization](https://build.fhir.org/organization.html)** in Care is a government
or administrative area, for example a state or a district. Care arranges these areas in
a hierarchy, from the country down to the ward. To open the hierarchy, select
**Organizations** in the Admin sidebar. Then select **Governance**.

Care attaches an organization to each facility and to each patient as the geo
organization. The geo organization is the government area that the facility or the
patient belongs to, for example a district.

Note: Care uses the word "Governance" for two different things. The **Governance** item
under **Organizations** holds the government organizations that this document describes.
The **Governance** section inside a responsibility links one responsibility to another.
See [Responsibility](../../concepts/access-governance/responsibility.mdx).

## Key Attributes

| Components | What it captures |
| --- | --- |
| Name | The name of the government or administrative area. Care requires a name. |
| Description | More detail about the organization. This attribute is optional. |

The name must be different from the names of the other organizations at the same level
of the same hierarchy.

### The hierarchy

Care shows the organizations as an expandable tree at the left of the page. Every
organization, except a top-level organization, has one parent. An organization can have
any number of children.

The government hierarchy levels include:

- Country
- State
- District
- Block Panchayat
- Corporation
- District Panchayat
- Grama Panchayat
- Local Body
- Municipality
- Ward

Note: The set of levels that your deployment uses can be different.

Note: Your deployment sets the maximum depth of the organization hierarchy.

### Level and parent

You do not enter the hierarchy level and the parent. Care sets them from the position in
the tree where you create the organization.

### Who can change the hierarchy

Only a Care superuser can create, change, or delete a government organization. Other
users see the government organizations that they have access to. Care blocks their
changes to these organizations.
