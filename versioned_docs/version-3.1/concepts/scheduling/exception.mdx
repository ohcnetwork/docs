# Schedule Exception

## Definition

A **schedule exception** in Care is a period when a practitioner, a location or a healthcare service is not available.

An exception belongs to the resource, not to one template, so it applies to every [schedule template](../scheduling/schedule.mdx) of that resource. When you add an exception, Care removes the free slots of the resource that start inside it, on every day of the period. Care also does not make new slots that overlap it.

Care refuses an exception when a slot that has an appointment starts within the exception's times on one of its dates, start and end times included. The message is "There are bookings during this exception". An [appointment](../scheduling/booking.mdx) frees its place in the slot when it is cancelled or rescheduled.

You add and see exceptions on the **Exceptions** tab of the schedule page. The tab lists the exceptions that overlap the month shown on the calendar, and the calendar shows each exception as a striped band.

## Key Attributes

| Components | What it captures |
| --- | --- |
| Reason | Why the resource is not available, for example "Holiday Leave". The form requires a reason, although Care itself does not. |
| Valid Period | The first date and the last date of the exception. Neither date can be before today. |
| From and To | The start time and the end time on each day of the period. Both are required. |
| Full Day Unavailable | Sets the start time to 00:00 and the end time to 23:59. |
| Resource | The practitioner, location or healthcare service that is not available. Care takes it from the schedule page that you open. |

Each exception card shows the reason, the times and the dates.

An exception cannot be edited. To change an exception, remove it and add a new one.

**Remove** on an exception card removes the exception after you confirm. Care warns that this cannot be undone.

When you remove an exception, Care marks it as removed. The removal does not by itself recreate the slots that Care removed when the exception was added.

### Valid Period

Both dates must be today or later, and the last date cannot be before the first date.

You can also add an exception from the calendar. Select a day that is today or later. In the pop-up, select **Add Exception**. Care fills in that day as the valid period.

### From and To

The same start time and end time apply on every day of the valid period.

Care has no separate full-day setting. It keeps only a start time and an end time for each exception.

**Full Day Unavailable** fills in 00:00 and 23:59 for you. The calendar shows an exception from 00:00 to 23:59 as a full day.

For part of a day, the start time must be before the end time. If the exception starts today, the start time must be later than the current time.

### Who can work with exceptions

| Permission | What it lets you do | Default roles |
| --- | --- | --- |
| Can list schedule on Object | See the exceptions of a resource. | Admin (facility role), Staff, Facility Admin, Doctor, Nurse and Administrator |
| Can Create on Schedule | Add and remove exceptions. | Admin, Staff, Facility Admin, Doctor and Nurse |

Care accepts Can Create on Schedule and Can list schedule on Object only in these places:

- For a practitioner: the facility's Administration organization, a department or team that the practitioner belongs to, or a parent of it.
- For a location: a department linked to the location or to its parent location, a parent of that department, or the facility's Administration organization.
- For a healthcare service with a managing organization: that organization or a parent of it. The Administration organization does not count.
- For a healthcare service without a managing organization: only the facility's Administration organization.

Only roles that you hold in the facility's organizations count. A role in a governance organization above the facility does not count.

**Add Exception** shows if you hold Can Create on Schedule in any department or team of the facility, or in its Administration organization.

**Remove** shows for everyone who can open the **Exceptions** tab. Care removes the exception only for a user who holds Can Create on Schedule in the right place. An Administrator sees **Remove**, but Care refuses the removal.
